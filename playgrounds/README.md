# React practice playgrounds

Each file is a self-contained interview exercise. Work through them in order.

| File | Focus |
| --- | --- |
| `01-filterable-product-list.tsx` | Controlled inputs, derived data, rendering lists |
| `02-user-profile-loader.tsx` | Interfaces, `useState`, `useEffect`, loading and error states |

For each exercise, begin by saying what state you need, what can be derived, and what the simplest usable version is.
