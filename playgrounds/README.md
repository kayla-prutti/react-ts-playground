# React practice playgrounds

Each file is a self-contained interview exercise. Work through them in order.

| File | Focus |
| --- | --- |
| `01-filterable-product-list.tsx` | Controlled inputs, derived data, rendering lists |
| `02-user-profile-loader.tsx` | Interfaces, `useState`, `useEffect`, loading and error states |
| `03-counter-stepper.tsx` | State updates and click handlers |
| `04-task-manager.tsx` | Interfaces, controlled forms, array updates |
| `05-shopping-cart.tsx` | Typed arrays, immutable updates, derived totals |
| `06-product-insights.tsx` | `useMemo` and derived data |
| `07-focus-form.tsx` | `useRef` and DOM interaction |
| `08-reducer-task-board.tsx` | `useReducer` and action functions |
| `09-local-draft.tsx` | Custom hooks and browser storage |
| `10-theme-context.tsx` | `useContext` and shared state |

For each exercise, begin by saying what state you need, what can be derived, and what the simplest usable version is.
